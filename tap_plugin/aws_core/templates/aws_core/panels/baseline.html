How each column is read
EBS default encryption
The footprint's ebs_encryption_by_default, from ec2:GetEbsEncryptionByDefault in that region.
S3 public-access block
The four account flags on the account the footprint BELONGS_TO_ACCOUNT, read once per account through s3control: on when all four are on, off when any is off. Every region row of an account shows the same value.
Config, GuardDuty, Security Hub, Access Analyzer
The recorder, detector, hub or analyzer the footprint HOSTS_*: on when one is recording, ENABLED, present or ACTIVE; off when one exists and none is. With no node it is unknown: the collector proves "not enabled" only with a complete, empty listing, and that statement is kept on the collection run, which this page cannot read. Security Hub is never shown off: AWS answers "not subscribed" with the same code as "access denied".
Control Tower
On when an enabled baseline that succeeded APPLIES_TO_TARGET the account or an OU above it; off when every baseline covering it failed; otherwise unknown.
